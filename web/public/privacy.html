Kosh — Privacy policy

Kosh is a personal finance app used by its owner only. It is not offered to the public.

What data Kosh uses

Transactions, accounts (last 4 digits only), budgets, goals and policy records that the user enters or that the Android app reads from the user's own bank SMS and payment notifications. Kosh never asks for or stores bank passwords, UPI PINs, OTPs or full card or account numbers.

Google user data

Kosh requests only the drive.appdata scope. It uses it to store the user's own data, encrypted with AES-256 using a key derived from the user's passphrase, in Kosh's hidden application folder in the user's Google Drive, so the user's phone and computer stay in sync. Kosh cannot see any other files in the user's Drive. Google data is not sold, shared with anyone, used for advertising, or used to train AI models.

Where data is stored

On the user's devices (encrypted on Android) and in the user's own Google Drive (encrypted). There is no Kosh server.

AI features

If the user adds their own Gemini API key, Kosh sends masked message text or monthly totals to Google's Gemini API to answer the user's questions. Account, card, phone and UPI identifiers are removed first.

Deleting data

Turning off sync and deleting the app removes local data. Drive data can be removed from Google Drive → Settings → Manage apps → Kosh → Delete hidden app data.
